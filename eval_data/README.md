# Evaluation data

`EPIC_100_P12_101.csv`: the human action annotations of video `P12_101` from **EPIC-KITCHENS-100**
(`EPIC_100_train.csv`, rows for this one video). Licence: CC BY-NC 4.0. Citation: Damen et al., "Rescaling Egocentric
Vision: Collection, Pipeline and Challenges for EPIC-KITCHENS-100", IJCV 2022. https://epic-kitchens.github.io/
The video and frames are not included; download them from the dataset site.
