# Pulse 模块设计（2026-11-01）

目标：一个能真实运行、拍得出来的演示——AI 一直在看、在听，但只在需要时才动用大模型。
原则：判断用 djev；"模型"一个配置入口（开发 gpt-6-luna，正式 muse-spark-1.3-contributor）；本地优先；不存视频和原始录音。

状态标记：✅ 已实现并测过 · 🟡 部分实现 · ⬜ 待做

---

## 1. 输入层（浏览器）⬜
- 摄像头：`getUserMedia`，每秒取 1 帧，缩到 640 px。
- 本地变化过滤：与上一张上传帧做灰度缩略图像素差，低于阈值不上传，省带宽和后端算力。
- 语音：浏览器 Web Speech API 输出整句文字（演示最简单）；不够用时切换到已有的本地流式 ASR（赛前代码，需标注）。
- 传输：一条 WebSocket，上行事件 `{kind, t, seg_id, rev, text | image}`，下行 tick、记忆变化、回答。
- 隐私开关：暂停、删除最近 N 分钟。

## 2. 事件与运行循环（Heartbeat）✅ 核心 / 🟡 调度
- 每个事件一次 tick：感知 → 写入工作记忆 → 一次判断读取 → 并发运行被触发的功能 → 确定性规则兜底 → 写长期记忆 → 推送轨迹。
- 已有：版本化输入（转写修订使旧事实失效）、过期结果拒绝、失败重试并显示"未完成"、判断器宕机时规则仍运行。
- 待做：
  - 事件队列与合并：画面高频时只处理最新关键帧；连续语音在同一句内合并。
  - 优先级：语音和提问优先于画面；长期记忆写入放后台，不阻塞下一个事件。
  - 计数：每个事件记录"是否唤醒模型"、耗时与估算费用，供界面计数器使用。

## 3. 感知（画面）🟡
- 去重：像素差 + 向量相似度（>0.95 视为重复）双重过滤。⬜ 两者都未实现（像素差放浏览器侧，向量相似度放后端）。
- 描述：djev 生成接口带图写一句话（实测 0.3–1 秒）。✅
- 带图判断：djev 是/否题（实测约 0.2 秒；4 帧合成画面物品与动作全对）。✅
- 注意：djev 的 span 是原文摘录，不能生成描述；描述必须走生成接口。

## 4. 判断题设计（heartbeat 的"直觉"）✅
- 原生是/否题（noul）、固定前缀锁定对象（"Does this utterance itself…" / "Does this image itself show…"）、窄问题写明排除项、每题单独阈值。
- 从工作记忆动态生成问题：每个待办任务一个"画面里是否在做这件事？"。
- 分层只在问题多时使用，第一层用功能包的具体入口问题，不用宽泛主题问题（30 句标注集实测：宽泛门控问题最弱）。
- 待做：问题集按哈希登记版本；实拍画面上重测一轮再调阈值。

## 5. 模型提供方（"Model" 角色）🟡
- 一个兼容 OpenAI 接口的提供方，三个配置：地址、模型名、密钥文件；dev/prod 两套配置，切换只改一处。✅（DeepSeek 已跑通，luna 已验证工具调用 2.3 秒、看图 8.9 秒）
- 能力：工具调用循环（单步动作可在工具执行后直接返回，省一次往返）✅；结构化输出（在证据帧上返回物品框坐标）⬜。
- 待做：超时与重试、调用费用统计、切换到 Muse 后的三项能力验证（工具调用、看图、框选）。

## 6. 工具 🟡
- 核心状态工具自己写：任务增改、物品位置、记忆读写。写入前检查输入版本，旧结果不能覆盖新状态。✅
- 外部工具走 MCP（官方 Python MCP 客户端）：黑客松只接 Google 日历（官方或社区 MCP 服务，需 OAuth 测试客户端）。⬜ 可选
- 复杂多步任务（整理邮件、写总结）赛后交给 Codex/Pi/DSH 会话作为"慢路径功能"。

## 7. 记忆与存储 🟡（目前全在内存）
四层：
| 层 | 内容 | 保留 |
|---|---|---|
| L0 感官缓冲 | 最近 60 秒画面与语音（内存） | 不落盘 |
| L1 情景记忆 | 关键帧缩略图 + 描述 + 向量 | 滚动 14 天，硬上限约 1 GB |
| L2 证据帧 | 被事实引用的画面（如"钥匙最后一次出现"） | 事实有效期间 |
| L3 语义记忆 | 文字事实、任务、每日摘要、向量 | 长期 |
- 存储：SQLite（事实、任务、情景、出处、版本）+ 向量（先 numpy，后 sqlite-vec/FAISS，256 维压缩）+ 图片按内容哈希存文件。
- 语音只存转写，不存录音。
- 夜间整理：当天情景压成文字摘要进 L3，过期 L1 画面删除只留描述和向量。黑客松做成手动命令。
- 检索顺序：结构化事实 → 向量检索（画面与语音分开排名，避免文字分数天然偏高的"模态差距"）✅ → 按时间排序。
- 估算：只存关键帧约 20 MB/天、约 600 MB/月；界面显示当日占用。

## 8. 功能包 ✅
- 日常包：任务（语音新建、改期、取消）、物品位置（画面）、看到在做就销账（画面 + 动态问题）、回答提问（工作记忆 + 长期记忆）。
- 手术室清点包保留为示例，不进演示。
- 每个包 = 判断题 + 功能 + 规则 + 上下文格式，换场景只换包。

## 9. 网页界面 ⬜
- 三栏：左 实时画面与字幕；中 heartbeat 流（每个事件的问题、概率、是否唤醒）与"N 个事件 / 唤醒 M 次"计数；右 任务、物品位置、回答卡片（证据帧 + 框 + 时间）与记忆占用。
- 纯静态页面 + WebSocket，后端用 FastAPI。
